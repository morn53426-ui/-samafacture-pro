Correspondances comptables automatiques

Affectez les ventes et les dépenses à des comptes de votre entreprise. Les changements ne modifient jamais les écritures déjà validées. Les fiches non classées et les lignes libres n'ont aucun compte automatique : choisissez explicitement leur compte avant de les comptabiliser. Attention : le réglage « produit catalogue » s’applique à tous les produits de ce type. En SYSCOHADA, 701 concerne les marchandises revendues sans transformation, 702 les produits finis fabriqués, 703 les produits intermédiaires, 704 les produits résiduels, 705 les travaux et 706 les services. Choisissez le compte selon la nature réelle de votre activité. Pour les dépenses, 638 est le compte de repli « autres charges externes » ; configurez un compte précis pour les catégories connues (loyer 622, déplacements 6181, assurance 625, etc.). Les comptes existants des entreprises ne sont pas renommés automatiquement.
