# Référence des écrans Sunupilot utilisés pour le montage

Les maquettes du nouveau montage ont été reconstruites à partir du code HTML source du dépôt, avec données fictives affichées comme démonstration. Ce document indique les bases vérifiées, pour éviter d'attribuer au logiciel des écrans ou fonctions imaginaires.

| Scène | Fichier source du dépôt | Éléments de structure repris |
|---|---|---|
| Facturation | `public/factures.html` | « Facturation », bouton « Créer une facture », statistiques Chiffre d’affaires / Factures payées / En attente / En retard, filtres de statut, colonnes Référence / Client / Émission / Échéance / Montant / Reste dû / Statut / Actions |
| Clients | `public/clients.html` | « Clients », Recherche rapide, Répertoire clients, colonnes Client / Contact / Montant dû / Total facturé |
| Rapports | `public/rapports.html` | Plage de dates, regroupement, boutons d'export, Paiements enregistrés / Dépenses / Écart paiements - dépenses / TVA inscrite sur factures, graphique des ventes |
| Tableau de bord | `public/dashboard.html` | Encaissements cumulés / Factures payées / Factures en attente / Solde net estimé, Évolution des ventes facturées, Répartition des ventes, Dernières factures |

## Limites importantes

- Les valeurs (FCFA, compteurs, références), les noms de clients et les contacts sont des exemples fictifs. Ils ne proviennent pas d'une base de données réelle.
- Les scènes sont des reproductions visuelles basées sur la structure HTML du dépôt, pas des captures d'écran faites dans un navigateur connecté à un compte.
- Les personnes sont des images de mise en scène générées et ne représentent pas des clients ou membres de l'équipe.
- Une capture authentique exige une session de démonstration authentifiée et des données de test préparées. Il ne faut jamais utiliser de données personnelles d'un vrai client dans une vidéo publique.

## Pour la prise de vue authentique

1. Ouvrir l'application sur un environnement de démonstration sécurisé.
2. Se connecter à un compte de test avec clients et documents fictifs.
3. Enregistrer les pages Facturation, Clients, Rapports et Tableau de bord à une résolution 1920 × 1080.
4. Masquer toute donnée personnelle, adresse email ou numéro de téléphone non fictif.
5. Remplacer les captures reconstruites dans le storyboard, puis refaire la recette vidéo et mobile.
