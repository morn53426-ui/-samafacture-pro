# Skills de design engineering — Sama Facture Pro

Les skills ci-dessous sont des copies du dépôt public [emilkowalski/skills](https://github.com/emilkowalski/skills), épinglées au commit amont `64eb3deb9a5fbfa041faf783e0bc3fd635872e9c`.
